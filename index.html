About PixVault

PixVault converts any image into a self-contained JSON file and back again.


Image → PixVault JSON → Share / Save → JSON → Image


Everything runs 100% locally. No uploads. No servers for core features.


Format version: 1 · Encoding: base64-data-url


Gallery and Camera use separate file inputs so mobile browsers correctly open Photos or the camera.
